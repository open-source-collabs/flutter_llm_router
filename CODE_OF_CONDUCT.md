# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We expect everyone to be respectful and constructive in issues, pull requests, and other project spaces. Harassment and personal attacks are not accepted.

Report unacceptable behaviour privately to the project maintainers through [a private GitHub report](https://github.com/open-source-collabs/flutter_llm_router/security/advisories/new). Maintainers will review reports and keep the reporter's identity confidential.
